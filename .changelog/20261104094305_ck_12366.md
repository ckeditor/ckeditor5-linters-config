---
type: Major breaking change
scope:
  - eslint-plugin-ckeditor5-rules
---

The `no-shadow-unsafe-dom-apis` rule now requires type information. Set `parserOptions.projectService` for the files that the rule checks, otherwise linting fails with an error. The rule now recognizes any value of the DOM `Document` or `Window` type, for example `global.document` from `@ckeditor/ckeditor5-utils`, and also reports restricted properties read through destructuring.
