The `no-shadow-unsafe-dom-apis` rule now recognizes the document, its body and the window through TypeScript types and reports restricted properties read by destructuring.

Newly reported:

* `const doc: Document = getDoc(); doc.activeElement;`
* `function f( win: Window | null ) { win!.getSelection(); }`
* `declare const doc: typeof document; doc.querySelector( '.foo' );`
* `( node as Document ).activeElement;`
* `const doc = el.ownerDocument; doc.activeElement;`
* `const f = ( doc = document ) => doc.activeElement;`
* `class Foo { private _doc: Document; bar() { this._doc.body.appendChild( el ); } }`
* `class Foo { constructor( private doc: Document ) {} bar() { this.doc.activeElement; } }`
* `const doc: Document = document; const { activeElement } = doc;`
* `const { body } = document; body.appendChild( el );`
* `function f( { activeElement }: Document ) {}`
* `const { getSelection } = window;`
* `const { shadowRoot, parentNode } = el;`
* `el.addEventListener( 'focusout', ( { relatedTarget } ) => {} );`

Still allowed:

* `import { Document } from './model/document.js'; const doc: Document = getDoc(); doc.activeElement;` (not the DOM `Document`)
* `function f( root: Document | ShadowRoot ) { root.activeElement; }`
* `const root: ShadowRoot = getRoot(); root.activeElement;`
* `const { activeElement } = someCustomObject;`
