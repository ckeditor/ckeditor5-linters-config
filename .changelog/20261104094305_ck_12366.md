The `no-shadow-unsafe-dom-apis` rule now uses type information, when available, to recognize any value of the DOM `Document` or `Window` type, for example `global.document` from `@ckeditor/ckeditor5-utils` or a `doc: Document` parameter. It also reports the restricted properties when they are destructured, for example `const { activeElement } = doc`, except in function signatures that are never run.
