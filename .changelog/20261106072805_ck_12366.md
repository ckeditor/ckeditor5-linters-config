---
type: Major breaking change
scope:
  - eslint-plugin-ckeditor5-rules
---

The `no-shadow-unsafe-dom-apis` rule now requires type information (`parserOptions.projectService` or `parserOptions.project`). It uses it to recognize any value of the DOM `Document` or `Window` type, for example `global.document` from `@ckeditor/ckeditor5-utils` or a `doc: Document` parameter. It also reports the restricted properties when they are destructured, for example `const { activeElement } = doc`.
